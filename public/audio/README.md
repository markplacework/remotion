# Audio assets

Drop royalty-free files here using these exact names, then uncomment the
`<Audio>` tags in `src/WapiAd.tsx`. Cue timing is documented in
`src/audio/soundDesign.ts`.

- `background-music.mp3` — bed for the full 15s, ducked under the notification/chime.
- `whatsapp-notification.mp3` — plays at the start of the Order scene (frame 180).
- `whoosh.mp3` — short transition swoosh, plays at each scene cut.
- `cta-chime.mp3` — subtle chime as the CTA card lands.

Do not use tracks with known copyright restrictions — pick from a
royalty-free library (e.g. YouTube Audio Library, Pixabay Audio, Epidemic
Sound if licensed) and confirm commercial-use rights for Meta Ads.
